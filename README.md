# Study Pace Tracker

A simple but smart study planner that helps you track your progress through tasks before a deadline.

## Features

- Break down your workload over a specific timeframe
- Track your progress and get real-time feedback
- Adapts daily based on your pace
- Provides motivational feedback based on your progress
- 100% local - data saved in your browser using localStorage
- No installation, no login, no backend required

## Installation

No installation needed! Just download the files and open `index.html` in your browser.

```
git clone https://github.com/nawidjavid/study-pace-tracker.git
cd study-pace-tracker
```

Then open `index.html` in your browser.

## Usage

1. Set up your study plan:
   - Enter what you're studying
   - Enter the total number of tasks
   - Set your deadline
   
2. Daily usage:
   - Log the number of tasks you complete each day
   - See your progress and get feedback on your pace
   - The app will tell you if you're on track, ahead, or behind
   
3. Data management:
   - Your data is automatically saved in your browser
   - You can export your data as a JSON file for backup
   - Import previously exported data if needed
   - Reset all data if you want to start fresh

## Why Use This?

Unlike simple to-do apps, Study Pace Tracker gives you dynamic feedback on your progress. It helps you:

- Understand if you're on pace to finish by your deadline
- Get motivation when you're falling behind
- Know when you can take a break if you're ahead
- See a history of your daily progress
